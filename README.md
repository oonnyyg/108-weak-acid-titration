# 一元弱酸强碱滴定计算工具

纯 Python 标准库实现的教学实验工具：从 JSON 实验配置生成完整滴定曲线，
逐点求解平衡方程并核查物料守恒与电荷守恒。

## 模型与假设

- 温度固定 25 °C，水的离子积 `Kw = 1e-14`。
- 一元弱酸 HA 解离平衡：`Ka = [H+][A-]/[HA]`；水自耦解离 `[OH-] = Kw/[H+]`。
- 强碱（如 NaOH）完全解离为一价阳离子，浓度按混合总体积稀释。
- 忽略活度效应（活度系数取 1）与混合体积收缩（体积可加）。
- 所有区域（初始点、缓冲区、当量点、过量碱区）使用同一个方程，
  不做分段近似拼接。对累计加碱体积 `Vb`：

  ```
  Vtot = V0 + Vb
  Ca   = C0 * V0 / Vtot        (酸总浓度，物料守恒)
  Cb   = Cb0 * Vb / Vtot       (强碱阳离子浓度)
  电荷平衡: [H+] + Cb = Kw/[H+] + Ka*Ca/(Ka+[H+])
  ```

  该残差关于 `[H+]` 单调，采用几何中点二分法在 `[1e-14, 1]` 上求解，
  相对收敛容差 `1e-12`，迭代上限 200 次；不收敛则报错，绝不输出伪造结果。

## 输入格式

JSON 顶层为实验数组，每个实验：

| 字段 | 含义 | 约束 |
| --- | --- | --- |
| `name` | 实验名称（可选） | 字符串 |
| `acid_volume_ml` | 酸初始体积 (mL) | 有限正数 |
| `acid_concentration` | 酸初始浓度 (mol/L) | 有限正数 |
| `ka` | 酸解离常数 | 有限正数 |
| `base_concentration` | 强碱浓度 (mol/L) | 有限正数 |
| `additions_ml` | 累计加碱体积列表 (mL) | 有限且 ≥ 0，保序、允许重复 |

单个实验配置错误只记入 `failures`，不影响其他实验。

## 使用方法

```bash
python -m titration examples/experiments.json --csv curve.csv --json summary.json
```

省略 `--csv` / `--json` 时结果写到标准输出。退出码：全部成功为 0；
存在失败实验且无成功结果时为 1；输入文件/JSON 错误为 2。

## 输出

- CSV 曲线：每点列出加碱体积、总体积、稀释后酸总浓度与碱阳离子浓度、
  `[H+]`、`[OH-]`、`[HA]`、`[A-]`、pH、电荷残差与物料残差。
- JSON 汇总：模型假设与求解精度、每个实验的理论当量体积
  `Veq = C0*V0/Cb0`、pKa、逐点浓度与残差，以及失败实验及原因。

## 验证方法

```bash
python -m unittest discover -s tests -v
```

测试覆盖：零加碱点与弱酸近似公式对照、半当量点 pH≈pKa、
当量点呈碱性、过量碱区逼近强碱极限、全曲线电荷/物料残差小于 1e-10、
非法输入拒绝、批量容错、输入顺序与重复点保留、CLI 端到端输出。
